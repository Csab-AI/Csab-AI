# Hunep Resource Planner

## Project Overview
The Hunep Resource Planner is a web application designed to facilitate resource allocation for construction projects. It allows users to manage projects, assign employees, and visualize project timelines through Gantt charts.

## Features
- **Project Management**: Create, update, and delete projects with start and end dates.
- **Employee Management**: Add, update, and delete employees along with their roles.
- **Resource Allocation**: Assign employees to projects with customizable percentage allocations.
- **Gantt Chart Visualization**: Generate Gantt charts to visualize project timelines and resource assignments.
- **Data Persistence**: Save and load application state using local storage.
- **PDF Export**: Export project and employee data to PDF format.

## Getting Started
1. Clone the repository:
   ```
   git clone https://github.com/yourusername/hunep-resource-planner.git
   ```
2. Navigate to the project directory:
   ```
   cd hunep-resource-planner
   ```
3. Open `index.html` in your web browser to view the application.
